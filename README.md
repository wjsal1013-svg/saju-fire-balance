# 火를 채우는 사주 리포트

음력 1971-06-12 19:30생 여성의 사주를 분석해, **부족한 화(火) 기운을 생활에서 보완하는 방법**과 **직업운·금전운·연애운·궁합**, 그리고 **2027년 전망**을 정리한 원페이지 웹사이트입니다.

## 사주 요약

| 구분 | 내용 |
|---|---|
| 양력 환산 | 1971-08-02 19:30 (음력 1971-06-12 평달) |
| 명식 | 辛亥 · 乙未 · 己未 · 甲戌 |
| 일간 | 己土 (음토, 신강) |
| 오행 | 목 2 · **화 0** · 토 4 · 금 1 · 수 1 |
| 용신 | 목(木) — 보조 화(火) |

## 핵심 진단

관성(목)은 월간·시간에 자리 잡고 있는데 **인성(화)이 0개**라
`관성 → 인성 → 일간`의 **관인상생(官印相生)** 고리가 끊겨 있습니다.

그래서 "일은 잘하는데 그 일이 명예·자격·안정으로 쌓이지 않는" 패턴이 반복됩니다.
화를 채우는 것이 곧 이 고리를 잇는 일이며, 이 사이트의 모든 보완법은 여기로 수렴합니다.

## 사이트 구성

1. **명식** — 사주팔자 네 기둥과 십성
2. **오행 분포** — 8자 기운 배분 시각화
3. **진단** — 과한 토 / 없는 화 / 조율점 목
4. **화 보완 8축** — 색·방위·계절·시간·맛·신체·공간·사람
5. **목 보완** — 용신 우선순위와 토 조절
6. **직업운** — 강점·약점·적합 직무·2026 병오년 흐름
7. **금전운** — 재성 구조, 새는 구멍, 축적형 재테크 원칙
8. **연애운** — 연애 스타일, 배우자궁, 2026 오미육합(午未六合)
9. **궁합** — 상대 일간 오행별 등급과 오래 가는 조건
10. **2027 전망** — 정미(丁未) 직업운·재물운, 월별 타이밍
11. **30일 실천 체크리스트** — 브라우저에 진행 상태 저장

## 기술 스택

- 순수 HTML / CSS / JavaScript 단일 파일 (`index.html`)
- 외부 빌드 도구·프레임워크 없음, GitHub Pages 바로 배포 가능
- Google Fonts (Jua / Noto Sans KR) 사용, 나머지는 전부 인라인
- 밝은 파스텔 테마 + 이모지 아이콘, 다크 모드 미지원
